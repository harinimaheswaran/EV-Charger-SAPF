# EV Charger Power Quality Improvement Using Shunt Active Power Filter

## Project Overview
This project focuses on improving power quality in electric vehicle (EV) charging systems using a Shunt Active Power Filter (SAPF).

The SAPF compensates for harmonic currents generated by nonlinear EV charger loads, thereby reducing source current distortion and improving power quality.

## Objectives
- To reduce current harmonics generated by EV chargers.
- To improve source current quality.
- To maintain DC-link voltage stability.
- To compare different synchronization techniques.

## Methodology
The following synchronization and control techniques are investigated:

1. Second-Order Generalized Integrator (SOGI)
2. Synchronous Reference Frame (SRF)
3. SRF with Two-Degree-of-Freedom PI Controller (SRF-2DOF PI)

A Voltage Source Inverter (VSI) is used to inject compensating currents into the system.

## Software Used
- MATLAB
- Simulink

## Expected Outcomes
- Reduction in Total Harmonic Distortion (THD).
- Improved source current waveform.
- Stable DC-link voltage.
- Comparative performance analysis of synchronization techniques.

## Conclusion
The project evaluates different synchronization strategies for SAPF-based harmonic compensation in EV charging applications.
